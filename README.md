# Ab Ai

تطبيق محادثة (PWA) مربوط بگروب تيليجرام عن طريق بوتين:

- **مجهول 1** (الأدمن) يرسل عن طريق البوت الأول، و**مجهول 2** (المستخدم) عن طريق البوت الثاني.
- أي شخص بالگروب "محادثة 1" يكدر يراسلكم من التيليجرام، ورسالته توصل للتطبيق.
- نص، صور، فيديو، رسائل صوتية، ملصقات تيليجرام (ثابتة ومتحركة وفيديو) مع حفظ حزم الملصقات.
- الدخول برمز، والجلسة تبقى محفوظة سنة.
- مسح يومي تلقائي للمحادثة (من التطبيق ومن الگروب).
- إشعارات (Web Push)، بدون زوم، وبدون تحديد أو نسخ للنصوص والصور.

## التشغيل على Vercel

1. **Vercel → Add New → Project** واختار هذا الريبو.
2. **Storage → Upstash for Redis** (مجاني) واربطه بالمشروع. يضيف `KV_REST_API_URL` و `KV_REST_API_TOKEN` تلقائياً.
3. **Settings → Environment Variables**:

| المتغير | القيمة |
|---|---|
| `BOT1_TOKEN` | توكن البوت الأول (الأدمن) |
| `BOT2_TOKEN` | توكن البوت الثاني (المستخدم) |
| `ADMIN_CODE` | رمز دخول الأدمن |
| `USER_CODE` | رمز دخول المستخدم |
| `SESSION_SECRET` | (اختياري) نص عشوائي طويل |
| `CRON_SECRET` | (اختياري) نص عشوائي لحماية المسح اليومي |

4. **Deploy** (يشتغل على الخطة المجانية Hobby)، وبعدها من **Deployments** سوّ Redeploy إذا ضفت المتغيرات بعد أول نشر.

## ربط الگروب

1. ضيف البوتين للگروب، وخلي **البوت الأول أدمن** (حتى يشوف كل الرسائل ويكدر يمسحها ويغير اسم الگروب).
2. اكتب أي رسالة بالگروب.
3. افتح التطبيق، ادخل برمز الأدمن، ومن القائمة ⋮ اختار **ربط البوتات بالگروب**.

## التثبيت كتطبيق

- **آيفون:** افتح الرابط بـ Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**. الإشعارات تشتغل بس من التطبيق المثبت (iOS 16.4+).
- **أندرويد:** Chrome ← ⋮ ← **تثبيت التطبيق**.
- بعد الدخول: ⋮ ← **تفعيل الإشعارات**.

## حدود لازم تعرفها

- حد رفع الملف 4 ميگا (حد Vercel). الصور تنضغط تلقائياً، بس الفيديو الأكبر من 4 ميگا ما ينرفع.
- منع السكرين شوت الكامل مستحيل بأي تطبيق ويب. التطبيق يمنع النسخ والتحديد والحفظ بالضغط المطول والزوم، ويغطي الشاشة لما يطلع للخلفية.
- المسح اليومي الساعة 3:00 فجراً بتوقيت بغداد.
